# Screenshots

Put the screenshots for the main README here, using these file names:

| File | What to capture |
|---|---|
| `overview.png` | The top of the dashboard with the metrics and the Behavior Trends tab |
| `ask-ai.png` | The 🤖 Ask AI tab with a question and its answer |
| `why.png` | The 🔍 Why? tab showing the revenue waterfall chart |
| `action-plan.png` | The ✅ Action Plan tab with a saved plan in the tracker |
| `poster.png` | A promotion poster downloaded from the 📣 Brief & Promos tab |

Then, in the main `README.md`, remove the `<!--` and `-->` around each image line, and delete the 📸 placeholder line under it.

Tip: on Windows, press **Win + Shift + S** to take a screenshot, then save it from the notification.
